Random Forests in R

We start by loading the random forest package in R. We also split the data in training and testing data sets. 

library(randomForest)

n = nrow(whitewines)
ntest = round(n * 0.3)
set.seed(598)
test.id = sample(1:n, ntest)

Model Fitting

To fit the model, we use the randomForest function. Our goal is to predict the quality using all the other columns in the data matrix as potential predictors.

rf.wines = randomForest(quality ~ ., data = whitewines[-test.id,
    ], importance = T, ntree = 400)

The randomForest function outputs several quantities. Let us focus on mtry which is the number of variables selected for each split.

rf.wines$mtry
## [1] 3

In our example, mtry is set 3, aligning with the recommended value for regression-based Random Forest models: \(p/3\), where \(p\) is the number of predictors.

We can use the fitted model to make predictions, and we can calculate the average test error:

yhat.test = predict(rf.wines, whitewines[test.id, ])

sum((whitewines$quality[test.id] - yhat.test)^2)/length(test.id)
## [1] 0.411837

If we think about the training error, then the random forest approach leads us to two types of training errors: one based on the prediction function (using the training data) and the other one based on the out-of-bag samples.

yhat.train = predict(rf.wines, whitewines[-test.id, ])
sum((whitewines$quality[-test.id] - yhat.train)^2)/(n - ntest)
## [1] 0.07441902

We can see that the training error is significantly smaller compared to the prediction error.

sum((whitewines$quality[-test.id] - rf.wines$predicted)^2)/(n -
    ntest)
## [1] 0.3726565

The error based on the out-of-bag sample is closer to the testing error and a more reliable estimator to the model’s generalization performance.
We can also see how many times an observation was in an out-of-bag sample (below we only output the first 10 observatios for illustration purposes):

rf.wines$oob.times[1:10]
##  [1] 132 141 166 131 151 150 142 157 143 137



Performance Plots

We can visualize the performance of the random forest fitted model

par(mfrow = c(1, 2))
plot(rf.wines)

The function is plotting the MSE values derived from out-of-bag predictions. The plot shows that the model’s performance improves rapidly with the initial addition of trees but starts to plateau beyond a certain point. This suggests that adding more trees does not lead to overfitting, although one could potentially achieve similar performance with fewer trees.
