7.4b The Digits Recognition Example¶

Discriminant analysis in Python¶

To make the ideas concrete we use the handwritten ZIP-code digits from The Elements of Statistical Learning. In R the data originally in ElemStatLearn are now available in tensorBSS. Here we load the same flat files: each row is a label in $\{0,1,\ldots,9\}$ followed by a $16\times 16$ grayscale image stored as 256 pixels. The task is to classify the digit. We will try LDA, QDA, FDA, and naive Bayes.

ESL also provides a proper test set zip.test ($n = 2007$). Below we instead draw a small training/test split from zip.train so that the demonstration stays fast; you should feel free to repeat the analysis on the official zip.test.

Quadratic Discriminant Analysis (QDA)¶

With $p = 256$ pixels and only a few hundred observations per digit, each class covariance is rank-deficient. MASS::qda stops with an error. sklearn's QuadraticDiscriminantAnalysis will often fit anyway and emit a collinearity warning; the resulting rule is numerically unstable. A small reg_param is the analogue of the $\hat\Sigma_k + \eta I$ ridge used in the notes.

Fisher Discriminant Analysis (FDA)¶

Project the data onto the Fisher directions. In R these are lda()$scaling; in sklearn they are scalings_. For ten digits there are at most $K-1 = 9$ directions.

transform() applies the same map after centering, which is the preferred way to get LD / FDA coordinates. Multiplying by scalings_ alone skips the centering step and will not match transform().

In [42]:

Computational remarks¶

We can recover the same directions by forming $W$ and $B$ explicitly. In R this was a no-intercept dummy regression of the features on the class labels. The Python equivalent is: residuals $\mathbf{x}_i - \hat\mu_{y_i}$ and fitted values $\hat\mu_{y_i}$.

In [44]:
X = np.asarray(X_train, dtype=float)
y = np.asarray(Y_train)
n, p = X.shape
classes = np.unique(y)

mu = np.vstack([X[y == c].mean(axis=0) for c in classes])
class_index = {c: i for i, c in enumerate(classes)}
mu_y = np.vstack([mu[class_index[ci]] for ci in y])  # fitted class means
R = X - mu_y                                         # residuals

W = np.cov(R, rowvar=False, bias=False)              # within-class / pooled
B = np.cov(mu_y, rowvar=False, bias=False)           # between-class (R: cov(fitted))

eigvals_W, eigvecs_W = np.linalg.eigh(W)
print("W eigenvalues: min / median / max =",
      eigvals_W.min(), np.median(eigvals_W), eigvals_W.max())
print("Number of nonpositive eigenvalues of W:", np.sum(eigvals_W <= 0))

# W^{-1/2}, with a floor on tiny/negative eigenvalues
ev = np.clip(eigvals_W, 1e-8, None)
A = (eigvecs_W * (1.0 / np.sqrt(ev))) @ eigvecs_W.T
