Birthweight Data Set Example¶

The birthweight.csv data set contains data from a study on the birth weight of 42 babies. The variables in the data set are the following:

  • ID: Unique Identification number of a baby
  • Length: Length of the baby at time of birth in cm ($X_1$)
  • Birthweight: Weight of the baby at time of birth in kg ($Y$)
  • Headcirc: Head circumference of the baby at time of birth in cm ($X_2$)
  • Gestation: Completed weeks of gestation ($X_3$)
  • smoker: Mother is/is not a smoker {0: No, 1: Yes} ($X_4$)
  • mage: Mother's age at time of birth ($X_5$)
  • mnocig: Mother's number of cigarettes smoked per day ($X_6$)
  • mheight: Mother's height in cm ($X_7$)
  • mppwt: Mother's pre-pregnancy weight ($X_8$)
  • fage: Father's age at time of birth ($X_9$)
  • fedyrs: Father's years of education ($X_{10}$)
  • fnocig: Father's number of cigarettes smoked per day ($X_{11}$)
  • fheight: Father's height ($X_{12}$)

The residuals $\mathbf{r}$ are used to estimate the error variance: $$\hat{\sigma}^2 = \frac{1}{n-p-1}\sum_i r_i^2 = \frac{\text{RSS}}{n-p-1}$$

To obtain an estimator for $\hat{\sigma}$, we can either use the formula (from the notes):

In [12]:

print(f"Manual RSE calculation: {rse:.6f}")

The coefficient of determination computes as: $$ \frac{\sum_i (\hat{y}_i - \bar{y})^2}{\sum_i (y_i - \bar{y})^2} = 1 - \frac{\text{RSS}}{\text{TSS}}$$ We can extract $R^2$ from the output or compute it:

             birthweight['Birthweight'].mean()) ** 2)
r_squared_manual1 = 1 - (rss / tss)
r_squared_manual2 = 1 - np.var(full_model_residuals) / \
    np.var(birthweight['Birthweight'])

$R^2$ and $\text{RSS}$ behavior when adding more $X$'s¶

We can also visualize how the $R^2$ and $\text{RSS}$ change as a function of the number of variables in the model to observe that adding a new predictor, even if it is randomly generated and has nothing to do with $Y$ will decrease $\text{RSS}$ and therefore increase $R^2$.

So, start with the null model that contains only the intercept and then we add variables one at a time, keeping the $R^2$ and $\text{RSS}$ that we will plot in the end. We will also randomly generate a new variable randomvar to illustrate that even an unrelevant variable has an effect on both $R^2$ and $\text{RSS}$ :

In [17]:
birthweight_new = birthweight.copy()
birthweight_new['randomvar'] = np.random.normal(size=birthweight_new.shape[0])
predictors = birthweight_new.columns.drop(['Birthweight']).tolist()

rsq = []
rss = []

# Model with only intercept
intercept_model = smf.ols('Birthweight ~ 1', data=birthweight_new).fit()
rsq.append(intercept_model.rsquared)
rss.append(intercept_model.ssr)  # ssr is Sum of Squared Residuals

# Sequentially add predictors
for i in range(len(predictors)):
    current_predictors = predictors[:(i + 1)]
    formula = 'Birthweight ~ ' + ' + '.join(current_predictors)
    model = smf.ols(formula, data=birthweight_new).fit()
    rsq.append(model.rsquared)
    rss.append(model.ssr)

This is to illustrate why $R^2$ and $\text{RSS}$ are not good metrics when it comes to model selection. They are useful, because they helps us understand the quality of the model or $\text{RSS}$ is a key ingredient in constructing hypothesis tests, but they are never used for model selection.

As you see the $\beta_j$ that corresponds to the new variable cannot be calculated (hence the nan), since aveheight is linearly dependent on both mheight and fheight. At the same time, although the matrix $\mathbf{X}$ is not of full rank, statsmodel can produces solutions for the rest of the $\beta$'s using pseudo-inverse (with .fit(method='pinv')), and the fitted model is valid for prediction purposes. The predictions derived from this model will align with those obtained from fitting a linear regression model excluding the columns with nan coefficient.

This issue can be easily fixed, by removing one or more variables. Which variable will be removed depends on the context. For example, we need to (conceptually) answer the question on whether we prefer to have the aveheight or each parent’s height individually.

A harder issue to resolve is when two predictors are not exaclty linearly dependent, but approximately - this means that they are highly correlated, but not an exact function of one another. This is more challenging to deal with and we will discuss it later.

Test for the Significance of Predictors¶

We use the partial $F$ test $$F=\frac{\bigl(RSS_0 - RSS_{\alpha}\bigr)/(p_{\alpha} - p_0)}{RSS_{\alpha}/ \bigl(n-p_{\alpha} \bigr)}\, \sim \, F_{p_{\alpha} - p_0, n-p_{\alpha}}$$ to compare the full model with all available predictors versus the model that exclude father-related variables. That is, the hypothesis test is formulated as $$\begin{cases} &H_0: Y \sim 1+ \beta_{1} X_{1} + \ldots + \beta_{8}X_{8} \\ & H_{\alpha}: Y \sim 1+ \beta_1 X_1 + \ldots + \beta_{8}X_{8}+ \ldots + \beta_{12} X_{12} \end{cases} $$

In [20]:

reduced_formula1 = 'Birthweight ~ Length + Headcirc + Gestation + smoker + mage + mnocig + mheight + mppwt'
birthweight_mlr_reduced1 = smf.ols(reduced_formula1, data=birthweight).fit()

We can use one function to perform the test:

In [ ]:

Testing for all the predictors¶

The $F$ test statistic and corresponding $p$-value in the summary output correspond to the following hypothesis: $$\begin{cases} &H_0: Y \sim 1 \\ & H_{\alpha}: Y \sim 1+ \beta_1 X_1 + \ldots + \beta_p X_p \\ \end{cases} $$ which is the so-called overall $F$ test.

print(f"Overall F-statistic: {birthweight_mlr_full.fvalue:.4f}")
print(f"Overall F p-value: {birthweight_mlr_full.f_pvalue:.4e}")

Model degrees of freedom: 12.0
Residual degrees of freedom.: 29.0
Overall F-statistic: 8.7419
Overall F p-value: 1.0111e-06

In this case, the $F$ value is equal to 8.74 and it follows an $F_{12, 29}$ distribution.The corresponding $p$-value is equal to 1.0111e-06 which is much less than $\alpha=0.05$. This implies that we reject the null and conclude that the model with all the predictors is more adequate compared to the intercept-only model.

Training vs. Testing Error¶

In this example, and in linear regression models, as we introduce more variables, training error (measured by $\text{RSS}$ or $\text{MSE}$) consistently decreases. However, this reduction in training error does not guarantee a corresponding decrease in test error, which measures prediction accuracy on independent test data. To demonstrate this, we randomly split our dataset into $60\%$ training and $40\%$ test portions, progressively adding predictors.

In [30]:
# Using sklearn's train_test_split is the standard Python approach
X = birthweight.drop('Birthweight', axis=1)
y = birthweight['Birthweight']
p = X.shape[1]

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.4, random_state=42)

train_data = pd.concat([X_train, y_train], axis=1)
test_data = pd.concat([X_test, y_test], axis=1)

train_mse = []
test_mse = []
predictor_cols = X.columns.tolist()

for i in range(p):
    current_predictors = predictor_cols[:i + 1]
    formula = 'Birthweight ~ ' + ' + '.join(current_predictors)

    # Fit model on training data
    model = smf.ols(formula, data=train_data).fit()

    # Predict and calculate MSE for training set
    train_pred = model.predict(X_train)
    train_mse.append(np.mean((y_train - train_pred) ** 2))

    # Predict and calculate MSE for test set
    test_pred = model.predict(X_test)
    test_mse.append(np.mean((y_test - test_pred) ** 2))

# Plotting Train vs. Test MSE
plt.figure(figsize=(6, 6))
sns.lineplot(x=range(1, len(predictor_cols) + 1), y=train_mse,
         linestyle='--', marker='s', color='blue', label='Train MSE')
sns.lineplot(x=range(1, len(predictor_cols) + 1), y=test_mse,
         linestyle='-', marker='o' \
         '', color='red', label='Test MSE')
plt.xlabel("# of variables")
plt.ylabel("MSE")
plt.title("Train vs. Test MSE as Predictors are Added")
plt.legend()
plt.grid(True, linestyle='--', alpha=0.6)
plt.show()

In general, we expect that in each iteration, the blue line (representing the training error) consistently exhibits a monotonically decreasing trend, signifying the reduction of training error as more predictors are incorporated. On the other hand, the red line’s (testing error) trajectory may not uniformly decrease.

Test for Outliers¶

To identify outliers, we use the Bonferroni test. For that purpose, we need to compute the studentized residuals $t_{i}$ ( an externally standardized version of residuals ). Under the null hypothesis $H_{0}$, $t_{i} \sim t_{n-p-1}$, where $n$ is the sample size and $p$ is the number of predictors. We perform this test for all $n$ observations testing case at level $\alpha/n$:

In [31]:
# We work with the full model again.
n = birthweight.shape[0]
p = birthweight.shape[1]

We first compute the studentized residuals using the get_influence() function and the Bonferroni critical value using Student’s distribution:

In [32]:
# Computing Studentized Residuals
influence = birthweight_mlr_full.get_influence()
studentized_residuals = influence.resid_studentized_internal

# Critical value WITH Bonferroni correction
alpha = 0.05
bonferroni_cv = sp.stats.t.ppf(alpha / (2 * n), df=n - p - 1)
print(f"Bonferroni critical value: {bonferroni_cv:.4f}")

Bonferroni critical value: -3.6076

Now, we need to find which (if any) studentized residuals exceed the Bonferroni critical value:

In [33]:
# Sorting the residuals in descending order to find outliers (if any)
abs_studentized_resid = np.abs(studentized_residuals)
sorted_resid = np.sort(abs_studentized_resid)[::-1]
print("\nTop 10 absolute studentized residuals:")
print(sorted_resid[:10])

# Find outliers
outliers = sorted_resid[sorted_resid > np.abs(bonferroni_cv)]
print(f"\nNumber of outliers (residuals > critical value): {len(outliers)}")

Number of outliers (residuals > critical value): 0

Above, we computed a critical t-value of $\lvert-3.6076\rvert$ at $\alpha=0.05$. If an observation's studentized residual is higher (in absolute value) than this critical value, then this observation will be considered an outlier. According to this criterion, we can see that we don’t have any outliers in the data set, since none of the studentized residuals is higher than $3.6076$.

Collinearity: Car Seat Position Data (seatpos)¶

Car designers would find it helpful to know how different drivers will position the seat depending on their size and age. Researchers at the HuMoSim laboratory at the University of Michigan collected the following data on 38 drivers:

  • Age: Drivers age in years
  • Weight: Drivers weight in lbs
  • HtShoes: height with shoes in cm
  • Ht: height without shoes in cm
  • Seated: seated height in cm
  • Arm: lower arm length in cm
  • Thigh: thigh length in cm
  • Leg: lower leg length in cm
  • hipcenter: horizontal distance of the midpoint of the hips from a fixed location in the car in mm

This dataset originates from the faraway R package and a .csv version can be downloaded from Julian Faraway's Linear Models with Python repository.
