Student Performance Data Set Example¶

The student-mat.csv data set contains data from a study on student achievement in secondary education of two Portuguese schools. The data are based on the following publication:

"Using data mining to predict secondary school student performance" By P. Cortez, A. M. G. Silva. 2008. Published in Proceedings of 5th Annual Future Business Technology Conference.

and can be found in the UCI data repository: https://archive.ics.uci.edu/dataset/320/student+performance

The variables in the data set are the following:

  • school Student's school (binary: GP - Gabriel Pereira or MS - Mousinho da Silveira)
  • sex Student's sex (binary: F - female or M - male)
  • age Student's age (numeric: from 15 to 22)
  • address Student's home address type (binary: U - urban or R - rural)
  • famsize Family size (binary: LE3 - less or equal to 3 or GT3 - greater than 3)
  • Pstatus Parent's cohabitation status (binary: T - living together or A - apart)
  • Medu Mother's education level (numeric: 0 - none, 1 - primary education (4th grade), 2 - 5th to 9th grade, 3 - secondary education or 4 - higher education)
  • Fedu Father's education level (numeric: 0 - none, 1 - primary education (4th grade), 2 - 5th to 9th grade, 3 - secondary education or 4 - higher education)
  • Mjob Mother's occupation (nominal: teacher, healthcare related, civil services (e.g. administrative or police), at_home or other)
  • Fjob Father's occupation (nominal: teacher, healthcare related, civil services (e.g. administrative or police), at_home or other)
  • reason Reason to choose this school (nominal: close to home, school reputation, course preference or other)
  • guardian Student's guardian (nominal: mother, father or other)
  • traveltime Home to school travel time (numeric: 1 - <15 min., 2 - 15 to 30 min., 3 - 30 min. to 1 hour, or 4 - >1 hour)
  • studytime Weekly study time (numeric: 1 - <2 hours, 2 - 2 to 5 hours, 3 - 5 to 10 hours, or 4 - >10 hours)
  • failures Number of past class failures (numeric: n if 1<=n<3, else 4)
  • schoolsup Extra educational support (binary: yes or no)
  • famsup Family educational support (binary: yes or no)
  • paid Extra paid classes within the course subject (Math or Portuguese) (binary: yes or no)
  • activities Extra-curricular activities (binary: yes or no)
  • nursery Attended nursery school (binary: yes or no)
  • higher Wants to take higher education (binary: yes or no)
  • internet Internet access at home (binary: yes or no)
  • romantic With a romantic relationship (binary: yes or no)
  • famrel Quality of family relationships (numeric: from 1 - very bad to 5 - excellent)
  • freetime Free time after school (numeric: from 1 - very low to 5 - very high)
  • goout Going out with friends (numeric: from 1 - very low to 5 - very high)
  • Dalc Workday alcohol consumption (numeric: from 1 - very low to 5 - very high)
  • Walc Weekend alcohol consumption (numeric: from 1 - very low to 5 - very high)
  • health Current health status (numeric: from 1 - very bad to 5 - very good)
  • absences Number of school absences (numeric: from 0 to 93)
  • G1 First period grade (numeric: from 0 to 20)
  • G2 Second period grade (numeric: from 0 to 20)
  • G3 Final grade (numeric: from 0 to 20, output target)

Subset Selection via Level-wise algorithms & the leaps package¶


In [5]:
import itertools
import statsmodels.api as sm
import pandas as pd
import numpy as np

# Data
X = stu_performance.drop(columns="Grades")
y = stu_performance["Grades"]

# Full model MSE for Mallows' Cp
sigma2_full = performance_full.mse_resid

# max subset size
nvmax = X.shape[1]  

# we will store the best model per subset size
best_per_size = []

for k in range(1, nvmax + 1):
    best_model = None
    best_rsq = -np.inf
    
    # Loop over all combinations of size k using itertools combinations
    for combo in itertools.combinations(X.columns, k):
        X_subset = sm.add_constant(X[list(combo)])
        model = sm.OLS(y, X_subset).fit()
        
        if model.rsquared > best_rsq:
            best_rsq = model.rsquared
            best_model = {
                "k": k,
                "predictors": combo,
                "rsq": model.rsquared,
                "adj_rsq": model.rsquared_adj,
                "bic": model.bic,
                "aic": model.aic,
                "rss": model.ssr
            }
    
    # Compute Mallows' Cp
    best_model["cp"] = best_model["rss"] / sigma2_full - (len(y) - 2*len(best_model["predictors"]))
    best_per_size.append(best_model)


rs = pd.DataFrame(best_per_size)

Subset Selection via the step fucntion¶





We can use the **stepwise** approach to search possible models moving forward, backwards or in both directions (stepwise).

Python does not have a prebuilt function that mimicks the step function R. However, we can mimick this code using a for loop. Note that in the following function the default value for $k =2$, and uses AIC. The criteria can be changed to BIC by changing $k$ appropriately.


In [17]:
import numpy as np
import statsmodels.formula.api as smf

def stepwise_selection(model, k=2): # For BIC, use k=np.log(len(model.model.data.frame))
    """
    Performs bidirectional (forward/backward) variable selection based on a criterion.
    Takes a fitted statsmodels model as input, mimicking R's step().
    """
    df = model.model.data.frame
    response = model.model.endog_names
    
    # Get initial predictors from the model, excluding the intercept
    initial_predictors = {p for p in model.model.exog_names if p != 'Intercept'}
    
    # Get all possible predictors from the dataframe
    all_predictors = {col for col in df.columns if col != response}
    
    included = initial_predictors
    excluded = all_predictors - included
    
    while True:
        # Define the current best model and its criterion
        current_formula = f"{response} ~ {' + '.join(included) or '1'}"
        current_model = smf.ols(current_formula, data=df).fit()
        # The fix is here: using .df_model instead of .df_modelwc
        current_criterion = -2 * current_model.llf + k * current_model.df_model
        
        best_candidate_criterion = current_criterion
        best_move = None

        # Check backward moves (dropping a variable)
        for var in included:
            formula = f"{response} ~ {' + '.join(included - {var}) or '1'}"
            temp_model = smf.ols(formula, data=df).fit()
            criterion = -2 * temp_model.llf + k * temp_model.df_model
            if criterion < best_candidate_criterion:
                best_candidate_criterion = criterion
                best_move = ('drop', var)

        # Check forward moves (adding a variable)
        for var in excluded:
            formula = f"{response} ~ {' + '.join(included | {var}) or '1'}"
            temp_model = smf.ols(formula, data=df).fit()
            criterion = -2 * temp_model.llf + k * temp_model.df_model
            if criterion < best_candidate_criterion:
                best_candidate_criterion = criterion
                best_move = ('add', var)
        
        # If a better model was found, make the move
        if best_move:
            move_type, var = best_move
            if move_type == 'drop':
                included.remove(var)
                excluded.add(var)
            else: # 'add'
                excluded.remove(var)
                included.add(var)
        else:
            # If no move improves the criterion, stop
            break
            
    final_formula = f"{response} ~ {' + '.join(included) or '1'}"
    return smf.ols(final_formula, data=df).fit()

import numpy as np
from sklearn.linear_model import Ridge

alphas = np.logspace(-3, 3, 100)

coefs = []       
intercepts = []  

for a in alphas:
    ridge = Ridge(alpha=a, fit_intercept=False)  # intercept false to do it internally
    ridge.fit(X_train, Y_train)

    beta = ridge.coef_
    coefs.append(beta)

    # compute intercept "a0" like glmnet
    mean_X = X_train.mean(axis=0)
    mean_Y = Y_train.mean()
    a0 = mean_Y - np.dot(mean_X, beta)
    intercepts.append(a0)

beta_mat = np.column_stack(coefs)   
a0_vec = np.array(intercepts) 

ridge_lm = {
    "lambda": np.array(alphas),
    "beta": beta_mat,
    "a0": a0_vec
