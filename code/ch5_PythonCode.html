Section 5.3 Python Example¶

 

To illustrate the ideas in this chapter, we will predict house prices from a set of features including size, beds, zip, and a wealth index. This is a simulated example for illustration purposes, and the data can be found and downloaded in Section 5.3.

 

The response $y$ (house price) is obviously continuous, so we will fit linear and nonlinear regression models, this is the specified $\phi$ from the previous chapters, and then we will employ a neural net to learn $\phi_c$ using a squared error loss. In the end we will compare the results on the testing set.

 

Specifically, we will fit:

  1. OLS on the raw features, $\phi(x)=x$;

  2. OLS on a hand-built $\phi$ (a corner in size, and interaction $\mathrm{beds}\times\mathrm{wealth}$);

  3. OLS on a cubic in size plus the other raw features;

  4. a one-hidden-layer net with a linear last layer, two widths, with weight decay.

We will report $\frac1n\sum_i(\hat y_i-y_i)^2$ on a test set.

 

The approach used here is not a clone of nnet. You will also see that there are even differences in the results. It is not only the algorithms that differ, but also the training and testing data (even though the seed to split is the same). This is ok since the goal is not exactly to mimic what R is doing, but to perform the same type of analysis "in spirit" with the tools available in each language.

def design_matrix(df, dummy_cols=None):
    """size + beds + zip dummies (drop first) + wealth. Matches model.matrix(...,)[, -1]."""
    X_num = df[["size", "beds", "wealth"]].to_numpy(dtype=float)
    dummies = pd.get_dummies(df["zip"], drop_first=True, dtype=float)
    if dummy_cols is None:
        dummy_cols = list(dummies.columns)
    else:
        dummies = dummies.reindex(columns=dummy_cols, fill_value=0.0)
    X = np.column_stack([X_num, dummies.to_numpy()])
    names = ["size", "beds", "wealth"] + [f"zip_{c}" for c in dummy_cols]
    return X, names, dummy_cols

X_tr_raw, xnames, dummy_cols = design_matrix(train)
X_te_raw, _, _ = design_matrix(test, dummy_cols=dummy_cols)

2. Hand-built $\phi$¶

In the simulated data, we have a a floor on size at $1100$ ft$^2$, and $\mathrm{beds}\times\mathrm{wealth}$. So, we fit an OLS that matches this specific behavior:

In [35]:
def phi_matrix(df, dummy_cols):
    size_corner = relu(df["size"].to_numpy() - 1100)
    beds = df["beds"].to_numpy(dtype=float)
    wealth = df["wealth"].to_numpy(dtype=float)
    beds_wealth = beds * wealth
    dummies = pd.get_dummies(df["zip"], drop_first=True, dtype=float)
    dummies = dummies.reindex(columns=dummy_cols, fill_value=0.0)
    X = np.column_stack([size_corner, beds, wealth, beds_wealth, dummies.to_numpy()])
    names = ["size_corner", "beds", "wealth", "beds_wealth"] + [f"zip_{c}" for c in dummy_cols]
    return X, names

X_tr_phi, phi_names = phi_matrix(train, dummy_cols)

4. One-Hidden-Layer Net¶

sklearn.neural_network.MLPRegressor with activation="logistic" and solver="lbfgs" is the closest stand-in for R nnet(..., linout = TRUE):

$$ a=\sigma(W^{[1]}x+b^{[1]}),\qquad \hat y = W^{[2]}a+b^{[2]}, $$

sigmoid hidden units, linear last layer, L2 penalty (alpha $\leftrightarrow$ decay). The net sees only the scaled raw design, not size_corner or beds_wealth.

In [37]:
def fit_one_mlp(hidden=8, alpha=0.001, random_state=0, max_iter=2000):
    est = MLPRegressor(
        hidden_layer_sizes=(hidden,),
        activation="logistic",
        solver="lbfgs",
        alpha=alpha,
        max_iter=max_iter,
        random_state=random_state,
    )
    est.fit(X_tr, y_tr_sc)
    return est

def pick_best(hidden, alpha, n_starts, seed0):
    models = [fit_one_mlp(hidden, alpha, random_state=seed0 + i) for i in range(n_starts)]
    losses = [m.loss_ for m in models]
    return models[int(np.argmin(losses))]

nn8 = pick_best(hidden=8, alpha=0.001, n_starts=10, seed0=598)

The results we obtain are not surprising. The "hand-built" $\phi$ is the best, since it captures exactly the corner points. Obviously, this is not easy to guess in practice (when one does not know whether even to expect a corner). An experienced statistician might pick it up by looking at the residual plots.

A wider net with a tiny decay is quite close to the hand-picked OLS, without being told the columns which shows that the NN learned the shape of $phi$ with the two other NN closely follow.

The cubic OLS in size which fakes a bend, but misses the interaction has the worst fit even compared to the OLS over the raw features. There is a big difference from the results in R - the main reason is that the polynomials in R were standardized (avoiding collinearity issues) which is not the case here.
