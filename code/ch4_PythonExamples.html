Python Code for Examples in Chapter 4¶

Spline Basis Functions¶

This notebook demonstrates three common ways to construct cubic spline bases in Python:

  1. A custom truncated-power (radial) cubic spline basis
  2. B-spline bases via Patsy's bs()
  3. Natural cubic spline bases via Patsy's cr()

We use the same evaluation grid $x \in [0,1]$ and the same three interior knots $\{1/6,\, 3/6,\, 5/6\}$ throughout for easy comparison.

Truncated-power cubic spline basis¶

We first define a function that returns the full design matrix for a cubic spline expressed in a truncated-power basis. The basis consists of an intercept, a linear term, and one radial basis function $R(x,z)$ for each knot $z$.

import numpy as np
import matplotlib.pyplot as plt
from patsy import dmatrix
In [2]:
def R_xz(x, z):
    """Radial cubic basis function centered at knot z."""
    x = np.asarray(x)
    z = np.asarray(z)

    term1 = ((z - 0.5) ** 2 - 1 / 12) * ((x - 0.5) ** 2 - 1 / 12) / 4
    term2 = (
        (np.abs(x - z) - 0.5) ** 4
        - 0.5 * (np.abs(x - z) - 0.5) ** 2
        + 7 / 240
    ) / 24

    return term1 - term2


def cubic_spline_basis(x, knots):
    """Build the design matrix H = [1, x, R(x, z1), ..., R(x, zk)]."""
    x = np.asarray(x)
    knots = np.asarray(knots)

    H0 = np.ones_like(x)
    H1 = x
    H_knots = np.column_stack([R_xz(x, knot) for knot in knots])

    return np.column_stack([H0, H1, H_knots])

When fitting a regression model the same matrix $H$ serves directly as the design matrix.

We evaluate the basis on a fine grid and form a linear combination with fixed coefficients to illustrate a typical spline curve.

In [3]:
knots = np.array([1/6, 3/6, 5/6])
x = np.linspace(0, 1, 101)

H = cubic_spline_basis(x, knots)

beta = np.array([4, -0.05, -6, 2, 10])
f = H @ beta

B-spline bases with Patsy¶

In Python the function bs() from the Patsy package constructs B-spline basis functions. It is analogous to bs() from R’s splines package and is convenient for building design matrices for regression models. See the Patsy documentation on spline regression for further details.

Specifying knot locations¶

When the knot locations are known they can be passed directly via the knots argument. Below we evaluate cubic B-splines on the unit interval with interior knots at $1/6$, $3/6$ and $5/6$. The resulting design matrix contains one column for each basis function.

In [5]:
x = np.linspace(0, 1, 101)
knots = [1/6, 3/6, 5/6]

B_splines_basis1 = dmatrix(
    "bs(x, knots=knots, degree=3, include_intercept=False, "
    "lower_bound=0, upper_bound=1) - 1",
    {"x": x, "knots": knots},
    return_type="dataframe"
)

Specifying degrees of freedom¶

Instead of listing knots explicitly one can request a desired number of degrees of freedom with the df argument. For cubic B-splines Patsy places the required interior knots at suitable quantiles of the observed $x$ values. With df=4 the design matrix therefore contains four basis functions.

In [6]:
x = np.linspace(0, 1, 101)

B_splines_basis2 = dmatrix(
    "bs(x, df=4, degree=3, include_intercept=False, "
    "lower_bound=0, upper_bound=1) - 1",
    {"x": x},
    return_type="dataframe"
)

B_splines_basis2.columns = range(1, B_splines_basis2.shape[1] + 1)

Natural cubic splines with Patsy¶

In R, natural cubic spline bases are obtained with ns() from the splines package. The Python counterpart is Patsy’s cr() function (usually called through dmatrix). cr() produces a natural cubic regression-spline basis that is ready to be used as a design matrix. Details are available in the Patsy spline-regression documentation.

The individual basis functions generated by Patsy need not coincide with those produced by R’s ns(), because spline bases are not unique. They nevertheless span the same function space and serve the same modelling purpose.

knots = [1/6, 3/6, 5/6]
