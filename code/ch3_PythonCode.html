The Student Performance Example¶

In this final section we illustrate the practical implementation of the variable-selection and shrinkage methods developed earlier, using a real data example.

The analysis is based on the student-mat.csv data set, which contains information on student achievement in secondary education at two Portuguese schools. The original study is described in:

Cortez, P., & Silva, A. M. G. (2008). Using data mining to predict secondary school student performance. Proceedings of the 5th Annual Future Business Technology Conference.

The data are publicly available from the UCI Machine Learning Repository:
Student Performance data set.

The variables in the data set are the following:

  • school – student’s school (binary: GP – Gabriel Pereira or MS – Mousinho da Silveira)
  • sex – student’s sex (binary: F – female or M – male)
  • age – student’s age (numeric: from 15 to 22)
  • address – home address type (binary: U – urban or R – rural)
  • famsize – family size (binary: LE3 – ≤ 3 or GT3 – > 3)
  • Pstatus – parent’s cohabitation status (binary: T – living together or A – apart)
  • Medu – mother’s education (numeric: 0 – none, 1 – primary (4th grade), 2 – 5th–9th grade, 3 – secondary, 4 – higher education)
  • Fedu – father’s education (numeric: same coding as Medu)
  • Mjob – mother’s occupation (nominal: teacher, health, services, at_home, other)
  • Fjob – father’s occupation (nominal: same categories as Mjob)
  • reason – reason for choosing the school (nominal: home, reputation, course, other)
  • guardian – student’s guardian (nominal: mother, father, other)
  • traveltime – home-to-school travel time (numeric: 1 – <15 min, 2 – 15–30 min, 3 – 30–60 min, 4 – >1 hour)
  • studytime – weekly study time (numeric: 1 – <2 h, 2 – 2–5 h, 3 – 5–10 h, 4 – >10 h)
  • failures – number of past class failures (numeric: n if 1 ≤ n < 3, else 4)
  • schoolsup – extra educational support (binary: yes/no)
  • famsup – family educational support (binary: yes/no)
  • paid – extra paid classes in the course subject (binary: yes/no)
  • activities – extra-curricular activities (binary: yes/no)
  • nursery – attended nursery school (binary: yes/no)
  • higher – wants to take higher education (binary: yes/no)
  • internet – Internet access at home (binary: yes/no)
  • romantic – in a romantic relationship (binary: yes/no)
  • famrel – quality of family relationships (numeric: 1 – very bad to 5 – excellent)
  • freetime – free time after school (numeric: 1 – very low to 5 – very high)
  • goout – going out with friends (numeric: 1 – very low to 5 – very high)
  • Dalc – workday alcohol consumption (numeric: 1 – very low to 5 – very high)
  • Walc – weekend alcohol consumption (numeric: 1 – very low to 5 – very high)
  • health – current health status (numeric: 1 – very bad to 5 – very good)
  • absences – number of school absences (numeric: 0 to 93)
  • G1 – first-period grade (numeric: 0 to 20)
  • G2 – second-period grade (numeric: 0 to 20)
  • G3 – final grade (numeric: 0 to 20; the response variable)

Subset Selection via Level-wise algorithms¶


In [116]:
import itertools
import statsmodels.api as sm
import pandas as pd
import numpy as np

# Data
X = stu_performance.drop(columns="Grades")
y = stu_performance["Grades"]

# Full model MSE for Mallows' Cp
sigma2_full = performance_full.mse_resid

# max subset size
nvmax = X.shape[1]  

# we will store the best model per subset size
best_per_size = []

for k in range(1, nvmax + 1):
    best_model = None
    best_rsq = -np.inf
    
    # Loop over all combinations of size k using itertools combinations
    for combo in itertools.combinations(X.columns, k):
        X_subset = sm.add_constant(X[list(combo)])
        model = sm.OLS(y, X_subset).fit()
        
        if model.rsquared > best_rsq:
            best_rsq = model.rsquared
            best_model = {
                "k": k,
                "predictors": combo,
                "rsq": model.rsquared,
                "adj_rsq": model.rsquared_adj,
                "bic": model.bic,
                "aic": model.aic,
                "rss": model.ssr
            }
    
    # Compute Mallows' Cp
    best_model["cp"] = best_model["rss"] / sigma2_full - (len(y) - 2*len(best_model["predictors"]))
    best_per_size.append(best_model)


rs = pd.DataFrame(best_per_size)

Subset Selection via the step fucntion¶

 

We can use the stepwise approach to search possible models moving forward, backwards or in both directions (stepwise).

Python does not have a prebuilt function that mimicks the step function R. However, we can mimick this code using a for loop. Note that in the following function the default value for $k =2$, and uses AIC. The criteria can be changed to BIC by changing $k$ appropriately.


In [128]:
import numpy as np
import statsmodels.formula.api as smf

def stepwise_selection(model, k=2): # For BIC, use k=np.log(len(model.model.data.frame))
    """
    Performs bidirectional (forward/backward) variable selection based on a criterion.
    Takes a fitted statsmodels model as input, mimicking R's step().
    """
    df = model.model.data.frame
    response = model.model.endog_names
    
    # Get initial predictors from the model, excluding the intercept
    initial_predictors = {p for p in model.model.exog_names if p != 'Intercept'}
    
    # Get all possible predictors from the dataframe
    all_predictors = {col for col in df.columns if col != response}
    
    included = initial_predictors
    excluded = all_predictors - included
    
    while True:
        # Define the current best model and its criterion
        current_formula = f"{response} ~ {' + '.join(included) or '1'}"
        current_model = smf.ols(current_formula, data=df).fit()
        # The fix is here: using .df_model instead of .df_modelwc
        current_criterion = -2 * current_model.llf + k * current_model.df_model
        
        best_candidate_criterion = current_criterion
        best_move = None

        # Check backward moves (dropping a variable)
        for var in included:
            formula = f"{response} ~ {' + '.join(included - {var}) or '1'}"
            temp_model = smf.ols(formula, data=df).fit()
            criterion = -2 * temp_model.llf + k * temp_model.df_model
            if criterion < best_candidate_criterion:
                best_candidate_criterion = criterion
                best_move = ('drop', var)

        # Check forward moves (adding a variable)
        for var in excluded:
            formula = f"{response} ~ {' + '.join(included | {var}) or '1'}"
            temp_model = smf.ols(formula, data=df).fit()
            criterion = -2 * temp_model.llf + k * temp_model.df_model
            if criterion < best_candidate_criterion:
                best_candidate_criterion = criterion
                best_move = ('add', var)
        
        # If a better model was found, make the move
        if best_move:
            move_type, var = best_move
            if move_type == 'drop':
                included.remove(var)
                excluded.add(var)
            else: # 'add'
                excluded.remove(var)
                included.add(var)
        else:
            # If no move improves the criterion, stop
            break
            
    final_formula = f"{response} ~ {' + '.join(included) or '1'}"
    return smf.ols(final_formula, data=df).fit()

alphas = np.logspace(-3, 3, 100)

coefs = []       
intercepts = []  

for a in alphas:
    ridge = Ridge(alpha=a, fit_intercept=False)  # intercept false to do it internally
    ridge.fit(X_train, Y_train)

    beta = ridge.coef_
    coefs.append(beta)

    # compute intercept "a0" like glmnet
    mean_X = X_train.mean(axis=0)
    mean_Y = Y_train.mean()
    a0 = mean_Y - np.dot(mean_X, beta)
    intercepts.append(a0)

beta_mat = np.column_stack(coefs)   
a0_vec = np.array(intercepts) 

ridge_lm = {
