PSL: Smoothing Splines¶

Week 4 Example (Fall 2025)¶

A Simulated Example¶

In this example, we are going to reproduce the example from the ESL book in section 5.5.2 in which we the true function of the data is given by

$f(x) = \frac{sin(12 (x+0.2))}{x+0.2}, \, x\in[0,1]$

So, we are first going to simulate data from this curve:

In [2]:
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(598)
n = 100

x = np.sort(np.random.uniform(0, 1, n))
y = np.sin(12 * (x + 0.2)) / (x + 0.2) + np.random.normal(0, 1, n)

plt.scatter(x, y, color="blue", s=30, marker="o")

funf_x = np.arange(1, 51) / 50
funf_y = np.sin(12 * (funf_x + 0.2)) / (funf_x + 0.2)

plt.plot(funf_x, funf_y, color="gray", linewidth=2)

plt.show()

Fitting a Smoothing Spline model to the simulated data above¶

The function to use is LinearGAM and is part of the pygam library in Python.

The model is fitted as follows:

Choice of Lambda¶

The pygam package comes with an inbuilt option for smoothing parameters selection, primarily based on leave-one-out cross-validation (LOOCV) and generalized cross-validation (GCV).

There’s no need to specify lambda directly. Instead, we indicate the desired degrees of freedom (df), ranging from 0 to n. Python then determines the appropriate lambda. We can then consult both CV and GCV curves to decide the best lambda or df.

When using the LinearGAM function with a degree of freedom set at 9, the sum of leverages might not exactly match that number due to rounding errors.

The leverage output is equivalent to the diagonal entries of the smoothing matrix.

In [10]:
X_basis = gam._modelmat(x.reshape(-1, 1))
X = X_basis.toarray()

XtX = X.T @ X
XtX_inv = np.linalg.pinv(XtX)

H = X @ XtX_inv @ X.T

leverages = np.diag(H)
print("First 10 leverages:", leverages[:10])
print("Sum of leverages:", leverages.sum())
print("Effective df from gam:", gam.statistics_['edof'])
